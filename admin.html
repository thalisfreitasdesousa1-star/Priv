Editor local de conteúdo

Esta ferramenta permite preparar e validar perfis e fotos sem editar JSON manualmente. Não é um painel administrativo com login nem publica alterações automaticamente. Para publicar, copie o JSON gerado no arquivo data.json do GitHub e confirme o commit. Não coloque informações privadas neste arquivo: o conteúdo publicado é público.

Informações do site

Acompanhantes

Cadastre apenas pessoas adultas com comprovação de idade e autorização expressa de uso de imagem. Os campos “maior de idade” e “autorização” são declarações do administrador, não substituem a verificação.

Fotos do espaço

Cole links HTTPS de imagens reais já hospedadas. Uma foto por linha, no formato: URL | legenda.

Publicar alterações

Revise tudo antes de publicar. O GitHub fará o versionamento; se o Cloudflare estiver conectado ao repositório, poderá publicar automaticamente o commit.
